## ABIDE I – Autism Brain Imaging Data Exchange I

For my Deep Learning coursework, I propose using the **Autism Brain Imaging Data Exchange I (ABIDE I)** dataset. It is a publicly available research dataset containing resting-state functional Magnetic Resonance Imaging (rs-fMRI) data and phenotypic information from individuals diagnosed with Autism Spectrum Disorder (ASD) and typically developing (TD) controls. The aim is to investigate the use of brain functional connectivity data to distinguish between these two groups using deep learning techniques.
